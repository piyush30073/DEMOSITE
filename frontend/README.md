# Frontend

Next.js 15 + React + TypeScript starter dashboard.

- Install Node.js 20.9+.
- Copy `.env.example` to `.env.local`.
- Run `npm install` then `npm run dev`.
- Open http://localhost:3000.

The current page is an early lead-list integration shell. Add production authentication, secure server-side sessions, lead forms and role-aware pages before launch.
