# AdmissionFlow

Multi-tenant admission management platform for coaching institutes.

## Services

- `frontend/` — Next.js + TypeScript web application.
- `backend/` — FastAPI REST API, tenant-aware admission CRM and PostgreSQL persistence.
- `ai-service/` — FastAPI service for grounded course FAQ responses.

See each service README for setup. Copy `.env.example` files to local `.env` files and supply your own credentials. Never commit secrets.
